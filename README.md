# Email Delivery Tracker

Tracks how many sites have their contact form configured, their SMTP details received, and email delivery working.

**Live page:** https://hassannaveed2.github.io/email-config-checklist/

The whole app is one file, `index.html`. To change the site list or the starting status, edit the `SITES` array near the top of its script.

Ticks are saved in each person's browser, not in this repo. Never commit SMTP passwords here: the repository and the page are public.
